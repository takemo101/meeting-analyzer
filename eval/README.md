# 名前のヒントの評価（合成）

`meeting-analyzer actors try --cases` で、名前のヒント（SPEC §3.13）の当たり方を、同じ入力で数えるための、**合成した**データ。実在の人・会議とは関係ありません。**会議の本文は、置きません**（実会議の文字起こしは、コミットしない）。1 件の中の文を、**正解の話者ごとにまとめて**、1 人の話者の発話として、ヒントを出し、「先頭が正解」「ヒントに出た」を数える（正解が `null` の文は、使わない）。

| ファイル | 内容 |
|---|---|
| `actors-nouns.md` | 架空の 10 人。役割は短く、話題は語（API・データベースなど） |
| `actors-phrases.md` | 同じ 10 人。話題を、言いそうな言い方（「レスポンスが遅い」など）にしたもの |
| `cases.jsonl` | 100 件（160 文）。1 件は、確定した発話 1 つ＝文を話した順に並べたもの。各文に、正解の話者（`null`＝誰が言ってもよい文。評価には使わない） |

`tag`：`single`（1 文）・`run`（同じ話者の 2 文）・`turn`（話者が替わる 2 文）・`turn3`（A・A・B）・`filler`（相づち）。

```sh
# 判断モデルを取得して（約 1.2 GB）、ヒントの当たり方を数える
meeting-analyzer models download tiny-jev-0.6b
meeting-analyzer actors try eval/actors-nouns.md --judge tiny-jev-0.6b --cases eval/cases.jsonl
```

結果（話者の数・先頭が正解・ヒントに出た・1 人あたりの秒）は、[検証記録](../docs/verification.md)。サンプルが小さく、私が作った文なので、**方向を見るため**のものです。**以前の、文ごとの推定（確信度のしきい値で名前を決める）の記録は、検証記録に残っているが、いまは同じ数え方ができない**（会議の最中の推定を、やめたため）。
